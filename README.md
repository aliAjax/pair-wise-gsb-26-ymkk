# hxwl-12 心理咨询个案记录 · 跨设备续接台

远程会谈跨设备续接：记录每场会谈的设备、确认到的分钟与连接状态，掉线/换设备时从最后确认点续接，风险话题中断有冻结闸门，结束按确认点生成可版本化的纪要。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 持久化，BroadcastChannel 跨标签页实时同步，storage 事件兜底）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112。多开浏览器标签页即模拟“多台设备”，页面间状态实时同步；刷新/重开页面数据不丢失。

## 功能

- **每场会谈台账**：设备角色与机型（咨询师端/来访者端 × 手机/笔记本/平板/台式机）、接入时间、最后在线时间、连接状态（在线 / 网络中断 / 已停止）
- **确认点锚定**：咨询师按分钟确认分段；新设备接入先把同角色旧端置为“已停止”，进度回拨到最后确认分钟，绝不从未确认位置继续
- **掉线重连**：设备掉线显示中断状态；重连后从最后确认点续接，掉线期间内容需重新确认
- **风险闸门**：风险话题（自伤/自杀等）进行中掉线，进度冻结在最后确认点；必须由在线咨询师端确认来访者情绪稳定，才能解除冻结继续
- **会谈纪要**：结束时按确认点自动生成 v1，未确认内容不纳入；修订必须填写原因并另存为新版本，旧版本只读保留
- **可找回**：全部场次、事件流、确认点、纪要版本持久化在 localStorage，重开页面可继续查看；已结束场次可以咨询师端补录身份重新打开修订纪要

## 演示数据

1. `C-042`：风险话题中断、冻结中 —— 演练“确认情绪稳定 → 从确认点继续”
2. `C-119`：进行中，来访者端已从手机换到笔记本 —— 演练新设备接入/掉线重连
3. `C-203`：已结束，纪要含 v1 与一次带原因的 v2 修订 —— 演练版本查看与补录修订
