# hxwl-12 心理咨询个案记录

会谈时间线、风险等级与干预目标记录 —— 已扩展为**跨设备续接台**。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 跨设备续接台

- **设备台账**：每场会谈记录每台接入设备（来访者端/咨询师端）、连接状态（已连接/已掉线/已停止）与各自确认到的分钟
- **确认点**：会谈游标可逐分钟推进，"确认到当前分钟"由在线设备打出确认点，作为双方共同进度的锚
- **新设备接入**：新设备（或旧设备重连）接入时，同角色已连接的旧端先被停止，新端从最后确认的分钟接续
- **风险话题挂起**：掉线发生在风险话题段落时，进度保留在最后确认分钟，任意设备重连后仍挂起，须咨询师点击"确认情绪稳定"才能继续推进
- **纪要**：结束会谈按确认点自动生成纪要（段落确认情况、确认点流水、设备接续、风险处理、待跟进）；修改纪要须填原因并另存为新版本，历史版本可展开查看
- **持久化**：全部状态存入 localStorage（`hxwl12.continuation.v1`），重开页面可找回；可一键重置演示数据

## 页面结构

- 指标看板：进行中会谈 / 风险话题挂起 / 已确认分钟合计 / 纪要版本总数
- 会谈列表：切换个案，风险挂起有角标
- 续接台：时间线（段落、风险段、已确认进度、游标）+ 进度控制 + 设备管理 + 连接动态日志
- 会谈纪要：编辑器 + 版本历史
